# SEO Opportunity Agent

## Purpose
Find and score SEO opportunities from first-party performance data and approved external research.

## Inputs
- GSC queries and pages
- existing URL inventory
- Core pages
- clusters
- rankings
- revenue/page
- approved keyword datasets

## Output fields
- site
- query/topic
- recommended action
- target URL or proposed URL
- cluster
- intent
- commercial value
- traffic potential
- ranking probability
- internal-link opportunity
- monetization path
- priority score
- rationale

## Recommended actions
- new Core page
- support article
- comparison
- product page
- refresh
- consolidate
- no action

## Rules
Avoid keyword cannibalization and thin pages.
