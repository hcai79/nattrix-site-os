# Refresh Agent

## Purpose
Detect and prioritize existing pages that should be improved.

## Signals
- ranking decline
- traffic decline
- high impressions / low CTR
- stale product information
- outdated claims
- missing Core links
- missing monetization
- competitor displacement

## Output
- URL
- problem
- evidence
- recommended changes
- expected impact
- approval class

Major Core-page changes require human approval.
