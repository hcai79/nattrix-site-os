# Controlled Optimization

An Experiment record stores hypothesis, site_id, URL(s), proposed edit, impact/risk level, baseline, primary metric, guardrail metrics, observation window, approvals, rollout status, outcome, and rollback plan.

Agents may propose optimizations to CTAs, offer placement, internal links, refreshes and new clusters. High-revenue page changes, affiliate replacements, indexed URL or navigation changes require human sign-off. Do not run multiple uncontrolled changes to the same URL. Track concurrent changes. Evaluate commercial outcomes with sufficient traffic and windows; if evidence is inconclusive, mark inconclusive. Never automatically assume Google fluctuations prove a test winner.

Recurring jobs:
- daily: sync publishing/errors; site health alerts
- weekly: GSC and affiliate opportunity digest, five-content rolling plan, stale-offer audit
- monthly: site P&L, experiment review, content gap and roadmap revision
