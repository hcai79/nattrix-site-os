# Five-Site Pilot Matrix

| Site | Strategy | Main content format | Special review |
| --- | --- | --- | --- |
| CircuitsAtHome.com | electronics workbench equipment | tutorials / commercial guides | electrical safety and specs |
| SycamoreNet.com | ISP, WiFi, streaming troubleshooting | troubleshooting / comparisons | preserve existing traffic and URLs |
| TechVideoBlog.com | AI video software directory | tool profiles / best / vs / alternatives | pricing, product changes, affiliate disclosures |
| Sybari.com | security software directory | vendor profiles / comparisons | privacy/security claims |
| DogsForest.com | outdoor and hunting dog gear | buyer guides / use-case education | safety/animal welfare |

Stagger onboarding. Verify each site's actual existing content and Search Console performance before approving architecture or content plans. Maintain separate layouts and monetization policies. Five articles per week per site is a ceiling after QA, not an obligation.
