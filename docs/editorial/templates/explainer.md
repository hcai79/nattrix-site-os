# Explainer Template

## Required sections
1. H1
2. Plain-English Definition
3. Why It Matters
4. How It Works
5. Key Terms / Variables
6. Practical Example
7. Common Misunderstandings

## Rules
- Keep explanations practical.
- Use diagrams when concepts are easier to understand visually.
- Avoid padding simple concepts into long articles.
