# Buying Guide Template

## Required sections
1. H1
2. Quick Answer
3. Who This Guide Is For
4. Selection Criteria / How We Chose
5. Comparison Table
6. Best Overall
7. Best Value / Budget
8. Best for Specific Use Cases
9. Individual Product Sections
10. What to Look For
11. Common Buying Mistakes
12. FAQ
13. Final Recommendation

## Required metadata
- primary query
- intent
- Core cluster
- monetization path
- product IDs
- unresolved claims
- claims below 80 confidence
- internal-link targets
- visual requests

## Rules
- Core buying guides require human approval.
- Do not claim hands-on testing without evidence.
- Product rankings must prioritize user fit over commission.
- Comparison tables must use verified data.
