# Product Profile Template

## Required sections
1. Product Name
2. Quick Summary
3. Best For
4. Key Specifications
5. Strengths
6. Limitations
7. Compatibility / Use Cases
8. Alternatives
9. Related Buying Guides
10. Affiliate Offer References
11. Last Verified

## Rules
- Use structured product data.
- Never fabricate product imagery or specifications.
- Distinguish manufacturer claims from editorial assessment.
