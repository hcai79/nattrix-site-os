# Reviewer Feedback Loop

## Goal

Use human corrections to continuously improve agent behavior.

## Capture every material correction

Fields:
- article
- agent
- issue category
- original output
- reviewer correction
- reason
- severity
- reusable rule?
- date

## Issue categories

- factual error
- unsupported claim
- weak recommendation
- AI-sounding prose
- excessive length
- poor intent match
- missing answer
- incorrect internal link
- forced monetization
- visual inaccuracy
- source quality
- cannibalization

## Improvement cycle

Every 20 reviewed articles:
1. aggregate recurring corrections
2. identify systemic patterns
3. update relevant SKILL.md or editorial rules
4. test on next batch
5. compare correction rate

## Primary KPI

Human correction minutes per publishable article.

Secondary KPIs:
- factual error rate
- return-to-agent rate
- QA block rate
- post-publish corrections
