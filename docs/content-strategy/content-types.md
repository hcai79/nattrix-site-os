# Content Types

## Standard types

1. Hub
2. Buying Guide
3. Comparison
4. Product Profile
5. Tutorial
6. Troubleshooting Guide
7. Explainer

Each type should have its own template and QA rules.

## Visual requirements by type

### Hub
Use diagrams or category maps when they help users understand the ecosystem.

### Buying Guide
Prefer:
- comparison tables
- annotated product diagrams
- selection flowcharts
- concise visual summaries

### Comparison
Prefer:
- side-by-side feature graphics
- decision matrices
- use-case diagrams

### Product Profile
Prefer:
- product image
- labeled feature diagram
- specification summary graphic

### Tutorial
Prefer:
- step diagrams
- wiring/setup diagrams
- annotated screenshots when available
- process infographics

### Troubleshooting
Prefer:
- decision trees
- symptom-to-cause diagrams
- step sequence graphics

### Explainer
Prefer:
- concept diagrams
- charts
- simple schematics
- infographics
