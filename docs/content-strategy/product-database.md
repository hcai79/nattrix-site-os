# Product Database Strategy

## Goal

Maintain structured product records so commercial pages can reuse accurate product data without duplicating specifications manually.

## Initial fields

- Product name
- Brand
- Model
- Product type
- Typical price
- Key specifications
- Best for
- Pros
- Cons
- Affiliate offer references
- Related comparisons
- Related guides
- Last verified date

## Example

/products/rigol-dho804/

## Rules

- Never invent specifications.
- Separate manufacturer claims from editorial assessment.
- Never hard-code affiliate URLs into article content.
- Visual assets should reference approved product imagery or generated explanatory graphics, not fabricate product details.
