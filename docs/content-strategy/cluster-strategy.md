## Cluster rule

Each Core page should eventually have approximately 5-12 relevant supporting articles.

Example:

- What Is an Oscilloscope?

- Oscilloscope Bandwidth Explained
- How Many Channels Do You Need?
- What Is Sample Rate?

- How to Measure PWM
- How to Measure Frequency
- Oscilloscope vs Multimeter

Supporting content should link naturally to the relevant Core page.
