# Monetization Funnel

## Standard path

Informational Query
-> Supporting Content
-> Core Commercial Page
-> Product Profile
-> Affiliate Offer / Other Monetization

## Example

What Is Oscilloscope Bandwidth?
-> How Much Bandwidth Do I Need?
-> Best Oscilloscopes Under $500
-> Rigol DHO804
-> Merchant

## Secondary monetization

- display ads
- email capture
- sponsorships
- featured products
- future digital products

Every commercial page should have a clearly documented monetization path.
