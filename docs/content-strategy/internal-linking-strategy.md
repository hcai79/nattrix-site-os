# Internal Linking Strategy

## Primary relationship

Support -> Core -> Product

## Rules

- Link informational content to the most relevant Core page.
- Link Core pages to structured product profiles.
- Link between support pages only when helpful.
- Avoid repetitive exact-match anchors.
- Avoid inserting commercial links where they do not help the reader.
- Preserve existing valuable internal links unless a documented reason exists.

## Automation

The Internal Linking Agent should return:
- source URL
- target URL
- suggested anchor
- placement context
- rationale
- priority
