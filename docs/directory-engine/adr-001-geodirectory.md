# ADR-001: GeoDirectory evaluation (superseded)

Status: Superseded by ADR-002 (candidate decision; no plugin installed)
Date: 2026-10-08

GeoDirectory was initially selected as the WordPress directory layer. After reviewing Directories Pro documentation and its public demo, Directories Pro became the preferred candidate for BeautyInfoSpot, pending programmatic integration testing. GeoDirectory remains the fallback.

Do not deploy or implement GeoDirectory-specific integrations based on this superseded decision. Refer to ADR-002 for current architecture and acceptance gates.
