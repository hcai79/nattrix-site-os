# Core 30 Framework

## Definition

The Core 30 is a site's initial set of high-value commercial or conversion-focused pages.

Supporting informational content exists to build topical authority and route qualified visitors toward the relevant Core page.

## CircuitsAtHome initial hypothesis

Five clusters with approximately six commercial pages each:

1. Oscilloscopes
2. Multimeters
3. Soldering equipment
4. Logic analyzers
5. Bench power supplies

The number 30 is a planning framework, not a requirement to publish overlapping URLs.

Before publication, validate:
- search intent
- SERP overlap
- cannibalization
- product availability
- monetization path
- internal-link support

## Core page lifecycle

Planned -> Validated -> Briefed -> Drafted -> QA -> Approved -> Published -> Ranking -> Monetized -> Winner / Rework

## Winner criteria

A winner may be defined by:
- revenue per page
- affiliate EPC
- assisted conversions
- ranking position
- traffic growth
- email capture
- sponsor interest

Core 50 should be based on winners from the Core 30, not a predetermined list.
