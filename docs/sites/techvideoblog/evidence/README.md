## Safe use sequence

1. Read the page-specific freshness audit and its ledger.
2. Extract each existing factual statement into a separate claim row using the [shared evidence-ledger template](../../../editorial/templates/evidence-ledger.md).
3. Capture current first-party evidence with product, plan, region, billing, and policy context.
4. Reconcile linked reviews and identify every unresolved or contradictory claim.
5. Create a block-preserving staging brief only after high-impact claims are supported.
6. Obtain human approval before any Core 40 commercial-page change.

## Non-negotiable boundaries

- Do not infer a license, privacy, consent, training, retention, or commercial-use rule from a marketing page.
- Do not turn manufacturer claims into independent test results.
- Do not change live content, URLs, canonicals, redirects, taxonomies, affiliate treatment, or styling from these documents.
- The Captions AI route remains blocked pending [TVB-004](../owner-decision-register.md).
