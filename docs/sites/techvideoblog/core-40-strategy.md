# TechVideoBlog Core 40 Strategy

## Objective

Build TechVideoBlog around 40 high-intent directory and commercial pages. These pages become the site's stable conversion layer. Reviews, comparisons, platform pages, use-case pages, and AI-agent Posts should reinforce them through useful internal links, not compete with them.

The Core 40 is a working prioritization model based on the current published inventory. It is not a license to rewrite all pages, create thin pages, or change existing URLs.

## Core architecture

```text
Informational Post
  -> Category Pillar or Use-Case Pillar
  -> Tool Review or Comparison
  -> Centralized offer or future merchant destination
```

## Composition

| Layer | Count | Job |
| --- | ---: | --- |
| Category pillars | 12 | Own broad commercial intent and direct visitors to the right tool families. |
| Tool reviews | 10 | Build decision-stage authority around individual tools. |
| Comparisons | 10 | Capture head-to-head commercial evaluation intent. |
| Use-case and platform pages | 8 | Convert audience or workflow-specific demand. |

## Operating rules

1. Every new Post must have one primary Core 40 target, unless a documented reason says it should not monetize or route readers.
2. Each Core page needs a clear intent, updated evidence, a useful navigation path, and an explicit review date.
3. A category pillar should link to the most relevant review, comparison, and use-case pages. Do not duplicate rankings across sibling pillars without a user-fit reason.
4. Comparison pages should link to both product reviews and their shared category pillar.
5. AI-agent Posts should answer the query first, then add one natural contextual link to the appropriate Core page.
6. Do not modify a Core URL, canonical, or page hierarchy without recording backlink impact and receiving explicit approval.

## First execution waves

### Wave 1: Repair the conversion paths

- Complete remaining primary-hub broken-link mapping.
- Repair only exact or owner-approved candidates.
- Validate the Core 40 pages' page titles, visible H1, canonical, methodology, disclosure, and internal links.

### Wave 2: Strengthen money-page templates

- Prioritize the ten tool reviews and ten comparisons.
- Add evidence-backed verdicts, best-for and not-best-for guidance, dated pricing notes, alternatives, related links, and FAQs where helpful.
- Preserve claims only where testing or source evidence exists.

### Wave 3: Route the AI-agent cohort

- Assign every existing Post to one primary Core 40 page.
- Remove forced or duplicate commercial links.
- Create a targeted-fix, refresh, consolidate, or pass outcome for each Post.

### Wave 4: Add only validated gaps

- Validate the higher-level keyword seeds through SERP, demand, and intent research.
- Build a page only when it is distinct from the Core 40 and has a credible product and internal-link path.

## Success measures

- Zero broken internal links in primary conversion paths.
- Each Core 40 page has at least three relevant supporting internal links.
- Every high-intent AI-agent Post links naturally to its best Core target.
- Pricing, testing, and recommendation claims have review dates and evidence.
- Revenue, conversion, ranking, and backlink performance inform the next Core expansion.
