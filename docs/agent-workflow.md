# Agent Workflow

## Primary pipeline

1. SEO Opportunity Agent
2. Content Strategy Agent
3. Research Agent
4. Writer Agent
5. Visual Content Agent
6. SEO QA Agent
7. Internal Linking Agent
8. Monetization Agent
9. Human approval when required
10. WordPress publish/update

## Visual-content handoff

The Writer Agent identifies useful visual opportunities and creates a structured Visual Request.

The Visual Content Agent can produce briefs for:
- hero images
- infographics
- comparison graphics
- flowcharts
- decision trees
- concept diagrams
- process illustrations
- technical setup diagrams
- charts
- visual checklists

Technical or factual visuals must be grounded in the approved research pack. Safety-sensitive diagrams require human review.

## Existing-content pipeline

1. Refresh Agent detects performance change
2. SEO Opportunity Agent evaluates upside
3. Research Agent validates changed facts
4. Writer / editor proposes revision
5. Visual Content Agent updates or proposes visuals when needed
6. SEO QA validates
7. Monetization Agent checks commercial opportunities
8. Human approval for Core pages or material changes

## Portfolio-level prioritization

Portfolio Manager ranks proposed actions using:
- revenue potential
- traffic potential
- ranking probability
- existing authority
- commercial intent
- implementation effort
- risk
- strategic fit

The system should prioritize revenue impact, user value, and durable authority, not publishing volume.
