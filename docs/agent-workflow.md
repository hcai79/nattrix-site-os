# Agent Workflow

## Primary pipeline

1. SEO Opportunity Agent
2. Content Strategy Agent
3. Research Agent
4. Writer Agent
5. SEO QA Agent
6. Internal Linking Agent
7. Monetization Agent
8. Human approval when required
9. WordPress publish/update

## Existing-content pipeline

1. Refresh Agent detects performance change
2. SEO Opportunity Agent evaluates upside
3. Research Agent validates changed facts
4. Writer / editor proposes revision
5. SEO QA validates
6. Monetization Agent checks commercial opportunities
7. Human approval for Core pages or material changes

## Portfolio-level prioritization

Portfolio Manager ranks proposed actions using:

- revenue potential
- traffic potential
- ranking probability
- existing authority
- commercial intent
- implementation effort
- risk
- strategic fit

The system should prioritize revenue impact, not publishing volume.
