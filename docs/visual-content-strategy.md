# Visual Content Strategy

## Goal

Use visuals to make technical content easier to understand and commercial pages easier to evaluate.

## Priority order

1. Explanatory diagrams
2. Comparison graphics
3. Flowcharts / decision trees
4. Visual checklists
5. Charts using verified data
6. Product imagery
7. Hero images

## Examples for CircuitsAtHome

### Oscilloscope article
- bandwidth vs signal frequency diagram
- 2-channel vs 4-channel comparison graphic
- beginner buying-decision flowchart

### Multimeter tutorial
- probe placement diagram
- mode-selector explanation
- safe measurement workflow

### Soldering article
- tip shape comparison graphic
- soldering temperature guide using verified ranges
- bad joint vs good joint illustration

## Workflow

Writer identifies visual opportunity
-> Visual Content Agent creates visual brief
-> Research/QA verifies factual content
-> image-generation or design tool creates asset
-> SEO QA checks relevance, accuracy, alt text, and placement
-> publish

## Metrics

Track where possible:
- scroll depth
- time on page
- image engagement
- backlink/mention acquisition
- social sharing
- conversion lift on commercial pages
