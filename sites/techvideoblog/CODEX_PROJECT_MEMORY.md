# TechVideoBlog Project Memory

## Purpose

Authority directory for AI video tools, aimed at creators. Live site: `https://techvideoblog.com`.

## Production safety

- The WordPress MCP is connected to production.
- Default to read-only inspection.
- Publishing and updates require the owner to name the page and approve the exact scope.
- Preserve URLs, canonical tags, taxonomy paths, and existing structured fields unless a documented change is approved.
- Never put credentials or affiliate IDs in this repository.

## Verified setup snapshot

On October 8, 2026: WordPress 7.1.3, active ACF Pro, Rank Math Pro, Kadence, FacetWP, SearchWP, WP Rocket, Easy MCP AI, and other plugins. Pages and Posts are the primary public content structures.

All 88 currently inventoried Posts were modified between August and October 2026 and were published by an AI agent according to the owner. Treat this cohort as a prioritized QA and refresh population. Preserve URLs, backlinks, and canonicals while evaluating it.
