# TechVideoBlog Site Package

This package is the local operating record for TechVideoBlog. It intentionally excludes a WordPress export, credentials, affiliate IDs, and copied production content.

Current mode: **read-only discovery and local planning by default**. The owner has also
authorized narrow, reversible production updates for verified internal-link repairs and
page-level formatting or structure improvements. Each live change requires source
support, post-publish verification, and a `worklog.md` entry.

Production writes outside that bounded authorization require explicit owner approval for
the named target. See `docs/sites/techvideoblog/mcp-workflow.md` before using the
connected WordPress MCP.
